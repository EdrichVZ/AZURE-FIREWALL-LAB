# AZURE-FIREWALL-LAB
Demonstrate how to deploy and configure Azure Firewall to secure network traffic within an Azure environment. The lab includes configuring firewall rules, forced tunneling through custom routes, DNS configuration, and validating outbound filtering behavior.

## Objectives:
- Deploy an Azure Firewall
- Configure application and network rules
- Create a user-defined route (UDR)
- Force outbound traffic through Azure Firewall
- Configure custom DNS settings
- Test outbound filtering behavior
- Validate allowed and denied traffic
